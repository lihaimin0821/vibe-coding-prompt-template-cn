# Trae Solo CN 专用配置

> 本文件为 Trae Solo CN 优化的配置，包含针对国产 AI IDE 的特殊设置。

## 基本信息

- **IDE：** Trae Solo CN（字节跳动）
- **内置模型：** 豆包（默认）、DeepSeek
- **模式：** SOLO 模式、Builder 模式

## 工作流程遵循

1. 始终先读取 `START.md` 了解完整流程
2. 读取 `AGENTS.md` 了解当前阶段和任务
3. 参考 `agent_docs/` 获取技术细节
4. 遵循 计划→执行→验证 循环

## 模型选择策略

| 任务类型 | 推荐模型 | 原因 |
|----------|----------|------|
| 快速迭代/简单任务 | 豆包 | 响应快，对中文理解好 |
| 复杂架构设计/深度推理 | DeepSeek | 推理能力强 |
| 代码生成/调试 | 豆包 | 训练数据充足 |
| 研究/分析 | DeepSeek | 深度分析能力强 |

## 使用 SOLO 模式

对于完整的 MVP 开发流程：

1. 启用 SOLO 模式
2. 输入命令：`读取 START.md，我已经有明确的需求`
3. AI 将自动执行完整工作流

## 使用 Builder 模式

对于快速代码生成：

1. 切换到 Builder 模式
2. 描述需求：`创建一个用户登录页面`
3. AI 实时生成代码

## 常用命令

| 命令 | 说明 |
|------|------|
| "读取 START.md，直接开始" | 从需求开始完整流程 |
| "显示当前进度" | 查看 MEMORY.md |
| "运行测试" | 执行测试套件 |
| "部署到 Vercel" | 部署应用 |

## 产物优先记忆

为了避免上下文过载：

1. **写入文件而非聊天** — 让 AI 将重要信息写入文件
2. **压缩交接** — 当切换会话时，让 AI 写摘要
3. **加载摘要** — 新会话中加载摘要文件而非重头开始

## 验证循环

每个功能完成后：

```
1. 运行测试：npm test
2. 检查代码：npm run lint
3. 手动验证：浏览器测试
4. 更新 MEMORY.md
```
