## 工作流程

```
计划 → 执行 → 验证 → 继续
```

1. **先读文档：** 读取 `AGENTS.md`、`agent_docs/` 和 `docs/PRD-*.md`
2. **提出计划：** 概述实现方案，等待批准
3. **执行开发：** 一次实现一个功能
4. **验证结果：** 运行测试，检查代码
5. **更新记录：** 更新 `MEMORY.md`

## 代码规范

- **TypeScript：** 严格类型，禁止 `any`，使用 `unknown` + 类型守卫
- **格式化：** 使用 ESLint/Prettier，不允许警告
- **测试：** 新函数必须有单元测试
- **提交前：** 运行 `npm test` 和 `npm run lint`

## 受保护区域

未经批准不得修改：
- 基础设施代码（`infrastructure/`、`Dockerfile`）
- 数据库迁移文件
- 第三方集成配置

## 禁止事项

- ❌ 不得添加 MVP 范围外的功能
- ❌ 不得跳过测试
- ❌ 不得绕过失败的检查
- ❌ 不得使用已弃用的库

## 成功指标

完成每个功能后：
1. 运行测试：`npm test`
2. 检查代码：`npm run lint`
3. 手动验证：浏览器测试
4. 更新 `MEMORY.md`
