# 🚀 Vibe-Coding 快速启动器

> 适用于 Trae Solo CN 的 Vibe-Coding 工作流入口文件。

## 快速开始

在 Trae 中对 AI 说：

```
@agent 读取 START.md，我已经有明确的需求，直接开始
```

---

## 简化工作流程

```
💡 需求 ──► 📋 PRD ──► 🏗️ 技术设计 ──► 🤖 Agent配置 ──► 🚀 构建
```

| 阶段 | 时间 | 说明 |
|------|------|------|
| 需求确认 | 5分钟 | 你描述功能，AI整理 |
| PRD生成 | 5分钟 | 明确功能范围和优先级 |
| 技术设计 | 5分钟 | 确定技术栈和架构 |
| Agent配置 | 1分钟 | 生成编码指令 |
| 构建 | 开始 | 计划→执行→验证循环 |

---

## AI 会询问的问题

**第1问：** "请描述你的项目需求，包括核心功能和目标用户"

**第2问：** "列出必须有的3个核心功能（只要最关键的）"

**第3问：** "你偏好什么技术栈？或者让我推荐？"

**第4问：** "你的项目类型是什么？"

### 平台选择

| 类型 | 说明 |
|------|------|
| Web 前端 | React/Vue/Next.js 等 |
| Android | Kotlin + Jetpack Compose 等 |
| 后端服务 | Node.js/FastAPI 等 |
| 混合项目 | 前端 + 后端 + 移动端 |

---

## AI 将生成的文件

### 1. `docs/PRD-[项目名]-MVP.md` — 产品需求

- 功能列表（P0必备 / P1可选）
- 用户流程
- MVP边界（包含/不包含）

### 2. `docs/TechDesign-[项目名]-MVP.md` — 技术设计

- 技术栈选择
- 项目结构
- 核心组件设计

### 3. Agent 配置文件

- `AGENTS.md` — 编码指令
- `MEMORY.md` — 进度记录
- `agent_docs/` — 技术细节

## 快速示例

**你说：** "我想做一个待办事项 Android 应用，功能是添加、删除、完成待办项"

**AI 会问：**
1. "需要登录功能吗？"
2. "数据需要同步到云端吗？还是本地存储就够了？"
3. "UI 风格有偏好吗？Material Design 3？"

**你回答后，AI 自动生成：**
- PRD文档
- 技术设计（Kotlin + Jetpack Compose + Room）
- Agent配置文件
- 开始构建第一个功能

## 故障排除

| 情况 | 命令 |
|------|------|
| AI 做多余调研 | "跳过调研，直接进入PRD" |
| 过于复杂 | "简化方案，MVP最简方式是什么？" |
| 不满意结果 | "调整[功能]，重新生成" |
